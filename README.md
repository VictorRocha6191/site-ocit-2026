# ⚛️ Olimpíada de Ciência de Itapeva (OCIT 2026)

Bem-vindo ao repositório oficial do portal web da **1ª Olimpíada Regional de Ciências (OCIT 2026)**.

Este projeto é uma iniciativa educacional e de extensão universitária organizada pela **Universidade Estadual Paulista (UNESP) - Câmpus de Itapeva**, encabeçada por discentes e docentes da Engenharia de Produção. 

## 🎯 Sobre o Projeto
O site foi desenvolvido para ser o canal oficial de comunicação entre a universidade e as escolas públicas e privadas da região. O portal centraliza todas as informações operacionais do evento, incluindo:
* Regulamento oficial e manuais de inscrição.
* Calendário detalhado das fases e provas.
* Banco de materiais de estudo baseados na BNCC.
* Apresentação da comissão organizadora.

## 💻 Tecnologias Utilizadas
O desenvolvimento focou em criar uma plataforma leve, acessível e de fácil manutenção:
* **HTML5:** Estruturação semântica do conteúdo.
* **CSS3:** Estilização responsiva, utilizando Flexbox e CSS Grid para organização do layout e dos cards de membros.
* **JavaScript (Vanilla):** Lógica simples de navegação em página única (Single Page Application) para alternar as seções sem recarregar o site.

## ⚙️ Estrutura do Repositório
* `/css`: Arquivos de folha de estilo padronizados.
* `/img`: Recursos visuais, logotipos e fotos institucionais da comissão.
* `/docs`: Documentos oficiais em PDF (Regulamento, Inscrições e TCLE).
* `index.html`: Arquivo principal do portal.

## 📌 Status
Em operação para a edição de 2026. Atualizações de resultados e gabaritos serão integradas ao longo do cronograma oficial.
